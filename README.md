# 🥗 Dietary & Grocery Assistant

The Dietary & Grocery Assistant is an AI-powered application that helps users decide what to cook using the ingredients they already have at home. Users can upload a photo of their fridge or pantry, and the system uses AI-based image recognition to identify visible ingredients. Based on the detected ingredients, it suggests suitable recipes and identifies any missing ingredients required for the selected recipe. The missing items can then be added to a grocery shopping list using Todoist. The project is built using n8n for workflow automation and AI integration. It aims to make meal planning easier, reduce food waste, save time, and simplify grocery management. The workflow includes image upload, AI ingredient detection, recipe generation, missing-ingredient comparison, and shopping-list creation. Future improvements can include nutrition analysis, calorie tracking, expiry-date detection, personalized dietary recommendations, voice interaction, and budget-based grocery planning.

## 🛠️ Technologies Used
- n8n – Workflow automation
- AI/Vision Model – Image and ingredient recognition
- Todoist – Grocery list management
- Web Forms – Image upload
- JSON – Data exchange

## 🔄 Workflow
📸 Upload Image → 🤖 AI Vision → 🥕 Identify Ingredients → 🍳 Suggest Recipes → 🔍 Find Missing Ingredients → 🛒 Create Shopping List

## 🎯 Goal
To provide a simple and intelligent solution for meal planning and grocery management while helping users make better use of the food they already have and reduce unnecessary food waste.
